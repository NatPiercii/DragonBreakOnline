# Scripted objects inside the Bruma lock: what works on the server (30 Sep 2026)

Road to Alpha: "Some scripted objects don't work on the server." This is the census behind that line, and a fix
proposal per group. Tools beside this file: `scripted_census.py` (the objects), `pex_natives.py` (which vanilla scripts
call natives the server lacks). Puzzles and lever gates Nate removed stay removed and are not proposed back.

## How the server treats a script (evidence)

- **Script store.** The server's Papyrus VM loads scripts from `Skyrim - Misc.bsa` (the one archive in
  server-settings) and `data/scripts` (one file). Vanilla scripts are there; **no Beyond Skyrim (`CYR*`, `BSK*`),
  `manny_*`, Creation Club or USSEP script is**. A reference with a missing script logs `Script 'X' not found in the
  script storage` once per name per server start and has no server-side behaviour.
- **Skip rules** (`MpObjectReference.cpp`, live `/opt/alduinak`): scripts on exterior references of the first five
  plugins (form id < 0x05000000) are removed except `default2StateActivator` and `NorLever01SCRIPT`; everywhere, six
  scripts are removed on purpose (`CritterSpawn`, `PlayerBookShelfContainerScript`, `fxDustDropRandomSCRIPT`,
  `MineOreScript`, `manny_up_noticeboardScript`, `DA06PreRitualSceneTriggerScript`). Until fork `9cf18be2` (27 Sep) the
  list was longer (weapon racks, torch sconces, shrine blessings, traps...); since then those vanilla scripts run.
- **Natives.** A vanilla script that calls a native the server lacks logs `VirtualMachine::CallMethod - Method not
  found - 'X'` and that call returns nothing. Since 27 Sep 17:30: GetActorBase 14, Add 11, GetAngleZ 8,
  countLinkedRefChain 3, MoveToNode 3, GetCurrentPackage 3, setAV 2, getStageDone 2, isFurnitureInUse 1,
  evaluatePackage 1.
- **The gameplay layer** answers many objects before any script (`mp.onActivate` chain in gamemode.js).

## Scope

119,720 references: Cyrodiil inside the border polygon, the three small Bruma worlds, and 118 interior cells reached by
load doors. 2,211 of them are usable objects (activator, door, furniture, container, flora) with a script.

## Not usable objects (no proposal)

Quest and scene triggers (MS04, MS05, MS09, MS10, MS11, the Whitewood Creek event manager, bathhouse and balcony
triggers, `defaultSetStageTRIG*`, music and comment triggers), world-event triggers (CYRWETrigger), kill triggers and
the border gate (HelgenGate01, closed by the playtest lock anyway). They log the GetActorBase, Add, getStageDone and
GetCurrentPackage errors above. Traps (bear traps, tripwires, oil, spears, maces, falling rocks) are hazards; they run,
and their physics calls (setMotionType) have logged nothing since 27 Sep.

## Suggested order

1. GetAngleZ (C++, small, certain).
2. The Synod table gate and the bonfires (gameplay; need Nate's word on who may enchant there and what a bonfire does).
3. An in-game pass on weapon racks, torch sconces, nirnroot and fish, then MoveToNode or a rack container.
