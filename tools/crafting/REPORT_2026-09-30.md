## lab-repeated: what to measure

The server cannot know the second ingredient (the lab potion is a client-made form and the report names only what
left the player's inventory). Before a fix, a PC session reproduces it with the client's craft trace on: seated at a
lab, mix two ingredients where one is a Beyond Skyrim ingredient (every repeated id here is either a vanilla or a
BSAssets ingredient), and read the `Adding baseObjId` lines of `CraftService` in the client log. If both removals
report the same id, the engine's ContainerChangedEvent is the cause (a client-side dedupe by event order will not
help); if they differ, the report is built wrong.
