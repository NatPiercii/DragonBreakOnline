# Playtest plan, 2026-09-24: prove what is live before adding more

Every system below is live on the server but has never been played. The order puts the launch blockers first,
then the systems a new player meets in their first hour. Each session needs 2-3 testers plus one admin watching
`/var/log/skymp-server.log` (`bash ~/dragonbreak/dev-server.sh logs skymp 400`). A row passes only when what you see
**and** the log line both match. When something fails, the Discord bugs forum needs the time (UTC), who did it and what they saw.

**Before session 1 (Nat's PC):** a client package with fork `afb754e0` (switchable split repair, `repairResult` /
`hop` / `jump` reports) and `00c29dee` (jump crash guard, needs a flatrim/Native build). Sessions 2-6 can run on
0.3.31 if the package is late; session 1 cannot.

## 1. NPC stability (launch blocker, 40 min, needs the new client)

Near Bruma wildlife, 10 minutes per mode, same spot each time. An admin switches with `/driftrepair <mode>`.

| # | Do | Pass |
|---|---|---|
| 1 | `/driftrepair setPosition` (today's default), watch deer/wolves while a second player walks around | Baseline: count hops / rubber bands seen |
| 2 | `/driftrepair none` | Fewer visible jumps than 1; log `repairResult` lines |
| 3 | `/driftrepair moveTo` | log `repairResult ... joined` outnumbers `swapped` |
| 4 | `/driftrepair disableEnable` | same |
| 5 | Admin-panel teleport a tester somewhere far, then jump | No crash; SkyrimPlatform log shows `jump ignored` if the controller was missing |

Result: ship the mode whose `repairResult` reads `joined` most. If none does, the next job is where the stray body
is first created (`SpawnProcess`).

## 3. Law: arrest, jail, escape (40 min, needs a guard/official or admin)

| # | Do | Pass |
|---|---|---|

| 2 | At a cell door, "Imprison <name>" for 5 min | Door closes; prisoner sees the sentence; `/sentence` shows time left |

| 7 | Guard: release early, add 10 min, relock a picked door | Each works; bound hands still need the guard's X through the bars |
