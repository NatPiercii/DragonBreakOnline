Screenshot

In game, press Print Screen. Community Shaders saves the picture, usually in the Screenshots folder inside your Skyrim game folder. Any screenshot works, including one from Steam or the Windows Snipping Tool.

Check it first: screenshots can show other players' names and your chat. Staff see it in a private channel.

Logs

Add whichever of these you have. Paste a path into the file picker's address bar to jump straight to it. If your Documents folder is kept in OneDrive, look under OneDrive\Documents instead. The GOG, Epic and Microsoft Store editions use Skyrim Special Edition GOG, EPIC or MS in place of Skyrim Special Edition.

Launcher log
%APPDATA%\DragonBreak Online Launcher\install.log
Game log
%USERPROFILE%\Documents\My Games\Skyrim Special Edition\SKSE\skyrim-platform.log
SKSE log
%USERPROFILE%\Documents\My Games\Skyrim Special Edition\SKSE\skse64.log

Windows account names, passwords and session tokens are removed from logs before staff see them.
